# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is a fundamental priority for PocketPlan. Because PocketPlan is an offline-capable, client-side application running locally in the browser with zero external network tracking or third-party credential collection, your financial data never leaves your device.

If you discover a security vulnerability, please report it responsibly by contacting the maintainer via GitHub issues or email:
- Email: `raktim99.rd@gmail.com`

Please include:
1. Description of the vulnerability.
2. Steps to reproduce the issue.
3. Potential impact.

We will acknowledge receipt within 48 hours and provide a remediation timeline.
